# E-Commerce-Project


Hello, I’m Jai, a Data Analyst skilled in Python Power BI and SQL. I created an E-Commerce Sales Dashboard to analyze sales performance, trends, and KPIs across categories, stores, staff, and regions. This project delivers data-driven insights, improving business decision-making, customer understanding, and overall sales performance.

📊 E-Commerce Sales Analysis Dashboard
🧑‍💻 Project Overview

This project focuses on analyzing an E-Commerce Sales Dataset using SQL and Power BI to extract meaningful business insights.
The goal is to improve decision-making through data-driven analysis and interactive visual dashboards.

🎯 Objective

Analyze overall sales performance.
Identify month-wise and day-wise trends.
Understand product and category performance.
Track customer purchasing behavior.
Provide actionable insights for business growth.

🛠️ Tools & Technologies Used

SQL (Data Extraction & Data Cleaning).
Power BI (Data Visualization & Dashboarding).
Excel (Data Preparation).
DAX (Calculated Measures & KPIs).

📂 Project Workflow

Data Import & Cleaning using SQL.
Data Transformation and preprocessing.
Creating relationships between tables.
Building KPIs using DAX.
Designing interactive Power BI dashboards.
Generating business insights.

📊 Key Insights

Identified top-performing products and categories.
Analyzed seasonal and monthly sales trends.
Discovered high-revenue customer segments.
Evaluated overall business performance metrics.
Highlighted areas for sales improvement.

📌 Dashboard Features

Sales Overview Dashboard.
Time-Based Analysis (Month/Day trends).
Category & Product Performance Analysis.
Interactive Filters & Slicers.
KPI Cards (Revenue, Orders, Profit).
